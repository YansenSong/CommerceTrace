## 后端 Agent 能力

### 通用歧义识别与澄清

- 不再通过问题文本白名单逐条拦截特定问法。
- 设计结构化的歧义判定结果，至少覆盖指标口径、时间范围、比较基准、筛选维度和归因目标。
- 只有缺失信息会实质改变查询或结论时才请求澄清；可以使用安全默认值时，应明确告知采用的口径。
- 重新引入澄清状态前，先定义稳定的事件/API 契约，避免把某一种业务问题写进 Agent 主流程。
- 增加同义改写、否定表达、多歧义组合和无需澄清场景的评测用例。

### 通用时间范围与数据覆盖校验

- 使用结构化时间范围，而不是匹配“上个月”等固定词语。
- 统一解析绝对日期、相对时间、季度、同比、环比和自定义区间。
- 从数据源或 Schema 元数据获得各事实表的真实覆盖范围，不依赖 SQL 返回列名约定。
- 在执行查询前后统一校验目标时间与数据覆盖范围。
- 明确区分“业务值为 0”“查询无记录”“目标时间超出覆盖范围”和“数据源不可用”。
- 生成结论时引用覆盖范围证据，但不针对某个指标或某种时间表达硬编码文案。

## 评测与文档
