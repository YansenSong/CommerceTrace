# 17 — 从空环境验收的 MVP 发布候选

**What to build:** 让项目评审者从一个干净环境启动 CommerceTrace、完成初始化、体验简单查询与多步归因、回放证据和图表，并核验持续记忆与评测报告。最终交付需要清楚说明借鉴 Vanna 的部分和 CommerceTrace 自主设计的边界。

**Blocked by:** 14 — 完整分析历史回放; 16 — 持续记忆 Cold/Warm 与消融实验.

**Status:** ready-for-agent

- [ ] 标准启动流程从空卷依次完成数据库迁移、合成数据生成、场景验证、业务知识初始化、ChromaDB 索引重建、API 和前端启动。
- [ ] 健康检查区分数据库、数据集、知识登记和派生索引状态，并在未就绪时给出安全、可操作的诊断。

- [ ] SQL 应用层与数据库层安全测试、匿名用户隔离测试和主 SSE 端到端测试全部通过。
- [ ] README 提供项目定位、快速开始、配置、演示问题、架构、测试、评测复现和常见故障说明。
- [ ] README 明确列出从 Vanna 借鉴的单 Agent Tool Calling、工具契约、流式状态和交互理念，以及自主实现的 Evidence、双层 SQL 安全、Candidate/Trusted 边界和权威源设计。

- [ ] 项目展示的准确率、延迟、成本和记忆效果全部链接到实际生成的版本化评测报告。
