# 09 — 绑定真实查询结果的受控图表

**What to build:** 让用户可以把真实查询结果展示为指标卡、柱状图、折线图或饼图，同时保证模型只能选择受控图表参数，不能生成数据、执行 Python 或任意读取文件。

**Blocked by:** 08 — Evidence 约束的可追踪答案.

**Status:** ready-for-agent

- [ ] `visualize_data` 只接受受控图表类型、Evidence 或查询结果引用、标题以及明确的横轴、纵轴和值字段。
- [ ] 后端验证被引用结果属于本次请求，且所有图表字段真实存在于对应查询结果。
- [ ] 图表数据直接来自受控查询结果，不通过临时 CSV 文件、任意文件路径或模型生成的数据传递。
- [ ] 工具只返回符合允许范围的 Plotly JSON，不执行任意 Python、表达式、Shell 或用户代码。
- [ ] 指标卡、柱状图、折线图和饼图各有一个成功合同测试，并覆盖缺失字段、跨请求结果和不支持图表类型的拒绝行为。
- [ ] SSE 产生图表创建事件，前端在关联 Evidence 附近渲染响应式图表并保留数据表格。
- [ ] 图表失败不会删除已有 Evidence 或阻止系统基于已有证据返回文字答案。
