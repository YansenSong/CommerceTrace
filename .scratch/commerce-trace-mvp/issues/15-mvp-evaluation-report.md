# 15 — MVP 核心能力评测与报告

**What to build:** 让项目评审者可以在固定数据与配置下运行一套中文评测，得到基于 Golden SQL、结果哈希和场景断言的可复现报告，而不是依赖主观 LLM Judge 或预先宣称的成绩。

**Blocked by:** 06 — SQL 双层只读安全与错误修正; 13 — 销售额下降的有限多步归因.

**Status:** ready-for-agent

- [ ] 评测集约 60 个中文问题，覆盖简单聚合与趋势、多表指标、多步归因、歧义与无法回答、危险 SQL 与越权请求。
- [ ] 预置 Trusted Memory 与正式评测问题隔离，不提前保存评测问题或其同义表达。
- [ ] 主要正确性标签来自 Golden SQL、稳定结果哈希和植入场景断言，不以 LLM Judge 作为主要真实标签。
- [ ] 报告执行结果正确率、多步归因因素命中与贡献误差、SQL 首次成功率、自我修正率、澄清准确率和危险 SQL 拦截率。
- [ ] 报告定量结论 Evidence 引用完整率、平均 LLM 与工具调用次数、延迟和 Token 消耗。
- [ ] 运行记录数据种子、模型参数、Prompt 版本、知识版本和 Schema 指纹，确保结果具备复现实验所需元数据。
- [ ] 同一次运行输出结构一致的 JSON 与可阅读 Markdown 报告，失败样例包含安全化诊断。
- [ ] Fake LLM 快速评测可进入日常测试；真实模型评测需要显式标记、密钥和单独命令。
- [ ] 只有实际运行得到的数值可以被 README 或项目成果引用。
