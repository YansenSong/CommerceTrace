# 01 — 可流式运行的 CommerceTrace Walking Skeleton

**What to build:** 让项目评审者可以通过一条标准启动流程运行 PostgreSQL、FastAPI 与 React，在浏览器提交第一条中文消息，并看到由后端持续推送的结构化占位回答。这个切片建立后续所有能力共同依赖的请求、事件与端到端测试接缝，但不提前引入真实 SQL 或模型调用。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 从空环境执行标准启动流程后，数据库、后端与前端均能通过健康检查，前端能够访问后端。
- [ ] 浏览器可以通过 POST 提交中文消息并消费 `text/event-stream`，无需先建立 WebSocket 或轮询连接。
- [ ] 流至少覆盖会话开始、答案增量、答案完成和请求失败，并且每个事件都包含唯一事件标识、会话标识、请求标识、时间戳和结构化载荷。
- [ ] 前端能增量显示用户消息和占位回答，并在完成或失败后恢复输入状态。
- [ ] 自动化端到端测试从 FastAPI 请求入口消费完整 SSE 流，只断言公开事件契约和浏览器可观察结果。
- [ ] 日常测试不需要网络、真实模型密钥或外部服务。
