# 14 — 完整分析历史回放

**What to build:** 让匿名用户在刷新页面或重新打开历史会话后，看到与实时分析一致的计划、工具轨迹、Evidence、结果表格、图表和最终答案，同时避免重复 SSE 事件造成界面重复。

**Blocked by:** 02 — 匿名身份与持久化对话; 09 — 绑定真实查询结果的受控图表.

**Status:** ready-for-agent

- [ ] 对话持久化记录足以按原始顺序重建消息、计划步骤、工具调用与结果、Evidence、图表和请求终态。
- [ ] 历史读取始终按当前匿名用户隔离，并支持稳定排序和分页。
- [ ] 前端选择历史对话后可以渲染完整分析，而不需要重新调用 LLM、重新执行 SQL 或读取 ChromaDB。
- [ ] 实时流和历史回放使用兼容的稳定展示模型，技术实现细节不会作为模型隐藏思维暴露。
- [ ] 前端按 `event_id` 去重；重复接收同一创建、更新或答案增量事件不会产生重复卡片或文本。
- [ ] 完整 SQL 与工具参数默认折叠，Prompt、密钥、连接信息和原始技术错误永不显示。
- [ ] 浏览器端测试覆盖刷新恢复、切换会话、重复事件和两个匿名用户的历史隔离。
