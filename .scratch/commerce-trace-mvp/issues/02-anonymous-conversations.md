# 02 — 匿名身份与持久化对话

**What to build:** 让访客无需注册即可开始分析，并能在刷新页面后继续查看自己的对话历史。身份、会话与消息必须精确持久化和按匿名用户隔离，为后续工具轨迹与 Evidence 回放提供稳定归属。

**Blocked by:** 01 — 可流式运行的 CommerceTrace Walking Skeleton.

**Status:** ready-for-agent

- [ ] 首次访问时由后端创建匿名身份并设置安全 Cookie，客户端不能通过请求正文伪造用户身份。
- [ ] 新问题会创建或续用属于当前匿名用户的会话，并持久化用户消息与最终助手消息。
- [ ] 刷新页面后，同一 Cookie 可以按时间顺序分页读取自己的会话列表和消息历史。
- [ ] 前端提供新建对话、选择历史对话和恢复消息的最小交互。
- [ ] 服务端拒绝用户访问或续写不属于自己的会话，且不会泄露该会话是否存在的敏感细节。
- [ ] 集成测试使用两个匿名用户证明会话隔离、Cookie 连续性和消息排序。
